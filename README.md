# MT Photos — Android photo organiser

This repository contains the MT Photos Android project and GitHub Actions APK build.

The app displays photos locally, scans prominent foreground faces offline, groups similar faces into People albums, supports renaming and merging person albums, and stores the photo-scan checkpoints in its local `people.db` database. It does not upload photos or require a sign-in.

**IMPORTANT:** A fresh GitHub-built debug APK is not yet confirmed to have the same signing certificate as the previously installed beta. Do not uninstall the existing app or clear its data if you need to retain saved labels, album merges, and scan progress. Please check signing compatibility before attempting an update.
